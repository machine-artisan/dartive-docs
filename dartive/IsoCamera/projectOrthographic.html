projectOrthographic method

Offset projectOrthographic(
  1. Vec3 point, {
  2. double scale = 1.0,
})

Π(p) = scale·(right·p, −up·p) — projects a 3D point onto 2D screen space by dropping its component along forward entirely (no perspective divide) and keeping its components along right/up. screenY is negated because screen coordinates grow downward while up points toward positive world Y.

Linear (PRJ-2): Π(a·p + b·q) = a·Π(p) + b·Π(q), Π(0) = 0, and Π(forward) = 0. Parallel world lines stay parallel on screen.
