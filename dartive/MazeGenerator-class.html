MazeGenerator

MazeGenerator class Grid

A static, generated rectangular maze — one particular kind of Tilemap: a walled one. Extracted into dartive after the same recursive-backtracker algorithm had been hand-copied and re-adapted across three products in a row — my-rownie-run-item's original, ported into my-atlas-run-item's MazeBoard, then into my-astronaut-run-item's own MazeGenerator (square size only) — before raon-runner-platform-mockup/apps/maze-run-demo's village board needed a rectangular (20×10) board and made the duplication worth stopping. Extends Tilemap (not a separate concept from it) since the user asked for the "open board" case — a village with no walls — not to be confused with "a maze," the same distinction my-atlas-run-item's RunBoard.isMaze flag already drew between MazeBoard and AtlasRunBoard. See .context/decisions/0012-maze-and-joystick-extraction.md and 0014-tilemap-extraction.md. Standard "recursive backtracker" over the chambers at even coordinates; every odd-coordinate cell starts as a wall, and a wall slot between two chambers is removed exactly when the carve reaches between them. A fixed seed, so this is one learnable maze, identical every load — not regenerated per session. Pure Dart, no Flutter dependency, so it's directly unit-testable (agent-harness-patterns.md's "keep state and rendering separate," applied one layer further down than usual).

Math (GRD-3): chambers are the even-even cells; the carve is a randomized depth-first search, so the open cells form a spanning tree over the chambers — exactly one simple path between any two chambers (no loops, nothing unreachable).
