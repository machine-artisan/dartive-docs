VoxelPuppetPainter

VoxelPuppetPainter class Voxels

Renders a VoxelPuppet as flat-shaded, depth-sorted unit cubes under a given camera — backface-culled, and faces fully hidden by a neighboring voxel are skipped before that, so this stays cheap even at a puppet's full grid size. camera is a constructor parameter, not a fixed field, so the same puppet can be painted from several angles at once (see products/voxel-asset-bakery's multi-view panel for a consumer that does exactly that).

Math (VOX-2, VOX-3): a face with outward normal n is drawn only if it has no neighbor voxel and n·forward < 0 (it faces the camera). Faces are drawn far-to-near by mean corner depth p·forward (painter's algorithm). Shading is a fixed 3-tone by n_y (top unshaded, sides 22% darker, bottom 45%) — not Lambert lighting.
