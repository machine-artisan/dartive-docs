Breadth-first shortest path over a 4-connected integer grid — the standard unweighted-graph shortest-path algorithm, scoped specifically to "a small rectangular grid, 4-directional movement, every edge the same length," which is what a mini-game board typically is. Not a general graph library.

BFS, not DFS, on purpose: BFS explores in expanding rings, so the first time it reaches goal is guaranteed to be via a shortest path. DFS explores one branch to its end before backtracking — it can find a path, but not reliably the shortest one, which matters for anything meant to look like it's actually navigating rather than wandering.

Returns the path from start to goal inclusive (so path.first == start, path.last == goal), or null if no path exists. isBlocked decides whether a cell can be entered; width/ height bound the grid (cells outside 0..width-1 / 0..height-1 are never considered). If start == goal, returns a single-cell path [start].
