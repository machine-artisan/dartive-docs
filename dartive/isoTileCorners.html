isoTileCorners function Projection

List<Offset> isoTileCorners(
  1. IsoCamera camera,
  2. int x,
  3. int z, {
  4. double scale = 1.0,
  5. Offset origin = Offset.zero,
})

The 4 corners of one unit cell (x, z) of a ground-plane grid (y fixed at 0), projected through camera — in order (x,z) → (x+1,z) → (x+1,z+1) → (x,z+1), ready to build a quad for an isometric floor/wall tile. origin shifts the whole projection (e.g. to center a board on a canvas); scale matches IsoCamera.projectOrthographic's own scale.

Extracted into dartive after my-astronaut-run-item's _TerminalFloorPainter (features/terminal_game/screens/terminal_game_screen.dart) and raon-runner-platform-mockup/apps/maze-run-demo's village board needed the same tile-corner math — the geometry only, not that product's own wall-bevel/hazard-stripe styling, which stays product- specific per this package's "no full UI/theme" rule. See .context/decisions/0013-iso-grid-extraction.md.

Geometry (PRJ-4): the corners are origin + G·(x,z), G·(x+1,z), G·(x+1,z+1), G·(x,z+1) scaled — a parallelogram with screen area scale²·det G = scale²/√3, identical for every cell (translation invariance of a linear map).
