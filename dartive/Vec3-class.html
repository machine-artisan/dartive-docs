Vec3

Vec3 class Linear algebra

An immutable vector v = (x, y, z) ∈ ℝ³ in world space, with the factory's right-handed axes: +x right, +y up, +z forward.

Every operation returns a new value; nothing mutates. Equality is exact component equality (no epsilon) — compare computed results with a tolerance, e.g. closeTo, not ==.

Spec: doc/spec/linear-algebra.md (LA-1..LA-5).

See also: .context/decisions/0009-voxel-puppet-extraction.md (extracted from products/voxel-asset-bakery).
