perspectiveTurnY function Projection

Matrix4 perspectiveTurnY(
  1. double angleRadians, {
  2. double depth = 0.001,
})

A perspective "card flip" matrix that fakes a rotateY head/body turn for a flat 2D puppet with no real mesh — setEntry(3, 2, depth) adds the projective divide a plain rotateY lacks, so the far side visually compresses instead of just shearing. Apply around the part's own local origin (translate first, then canvas.transform(matrix.storage)).

rotateY turns around the vertical axis — like a door hinged top-to- bottom — so the visible motion is left/right. See perspectiveTurnX for the up/down sibling, and products/squishy-mascot-twin/README.md's background section for the hinge/globe intuition behind why that's not backwards.

First extracted from products/squishy-mascot-twin's mascot_painter.dart, where depth was tuned to 0.001.

Math (PRJ-6): M = P·R_y(θ), a 4×4 homogeneous matrix where P is the identity with entry (3,2) = depth, so w' = 1 + depth·z and the far half shrinks by 1/w'. Not affine (the last row is not (0,0,0,1)).
