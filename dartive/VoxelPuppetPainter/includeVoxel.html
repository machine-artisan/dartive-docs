includeVoxel

includeVoxel property

bool Function(int x, int y, int z)? includeVoxel
final

Restricts which voxels' faces this painter actually draws — hidden-face culling still checks the full puppet regardless (a voxel's neighbor is still "there" for culling purposes even when this filter excludes it from being drawn by this particular painter). Null (default) draws every visible face, unchanged from this class's original behavior.

Added for a real consumer need, not speculatively: a caller wanting to interleave one VoxelPuppet's rendering around a separate overlay widget (e.g. products/my-atlas-run-poc's own runner icon, painted between a "farther" and "nearer" pass for correct depth occlusion) used to have to build two genuinely separate VoxelPuppet copies to split one paint into two — which silently broke hidden-face culling for any voxel whose neighbor ended up in the other copy, since each copy only ever sees its own voxels. A face-level filter over one shared, complete puppet keeps culling correct while still letting the caller split what actually gets drawn where. See products/my-atlas-run-poc/.context/decisions/0012-voxel-painter-include-filter.md and this package's own .context/decisions/0011-voxel-painter-include-filter.md.
