dartive

dart + rive: small, all-Dart primitives for Flutter games. It covers an isometric camera, grid tilemaps and pathfinding, voxel puppets, and motion/input helpers. Each one is defined as a mathematical object with invariants that tests check.

Pre-1.0, factory-internal (publish_to: none). Primitives get extracted from a working product, never designed ahead of need. See CLAUDE.md in the source repo.

The spec is the contract

Every public behavior has a spec ID. Each tested ID has a test whose name starts with that ID, so a change request can name exactly what moves.

Category Spec IDs What it defines
Linear algebra linear-algebra.md LA-1…5 notation, Vec3
Projection projection.md PRJ-1…6, P1–P3 IsoCamera as a basis, Π, ground matrix G = S·R, tiles
Grid grid.md GRD-1…4, P1 Tilemap as (Ω, wall), BFS optimality, maze = spanning tree
Voxels voxels.md VOX-1…4 VoxelPuppet as a partial function, the cull/sort/shade pipeline
Motion and input motion-and-input.md MOT-1…3, P1 pulse curve, timer, joystick classification

Status markers on each page: ✅ proved by a test · 📄 documented only · 📝 proposed, not built.

The one picture to keep in mind

world (x, y, z) ──Π──▶ screen (sx, sy)          Π = scale·[right; −up], ker Π = forward
ground (x, z)   ──G──▶ screen                    G = diag(1, 1/√3) · Rotation
                                                 det G = 1/√3 ⇒ G⁻¹ exists at every azimuth

Writing a change request against the spec

Implement PRJ-P2 (isoCellAt). Acceptance: a [PRJ-P2] test proves
isoCellAt(isoTileCenter(x,z)) == (x,z) for x,z in 0..9 at azimuths 0/45/90.
Consumer: products/<name> (tap to select a cell). Don't change PRJ-1…5.

A good request names (1) the ID, (2) the invariant as an equation, (3) the test that will prove it, and (4) the product that needs it (rule 1). It also says which IDs must stay unchanged.

Use

final camera = IsoCamera();                       // α = 45°
final screen = camera.projectOrthographic(const Vec3(3, 0, 2), scale: 40);
final path = gridBfsPath(start: (0, 0), goal: (7, 3),
    isBlocked: maze.isWall, width: 10, height: 10); // shortest, or null

API reference

dart doc --output build/api .     # open build/api/index.html

This builds Javadoc-style HTML. Each spec page above appears as its category's landing page, so the spec and the member docs are one site. Every public member must have a doc comment (public_member_api_docs lint), and scripts/verify.sh checks both the lint and a dart doc dry run.
