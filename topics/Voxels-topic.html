Voxels (VOX)

VoxelPuppet, VoxelPuppetPainter, VoxelPuppetIo. Notation: linear-algebra.md; camera: projection.md.

Model

V : [0, size)³ ⊂ ℤ³ ⇀ Color            a partial function, stored sparsely
center(x,y,z) = (x,y,z) − (size/2 − ½)·(1,1,1)     the unit cube's world center
faces: 6 outward normals n ∈ {±e_x, ±e_y, ±e_z}

Rendering pipeline (one paint)

1. hidden-face cull   skip a face whose neighbor at cell + n is defined
2. back-face cull     skip a face with n·forward ≥ 0   (it faces away)
3. depth              depth(face) = mean over corners of (corner·forward)
4. sort               draw in descending depth (far → near, painter's algorithm)
5. shade              n_y > ½ → as-is · n_y < −½ → 45% toward black · sides → 22%

Note: the shading in step 5 is a fixed 3-tone look, not lighting. A Lambert term max(0, n·l) would be a new, proposed primitive (VOX-P1), not a bug fix.

Classes

VoxelPuppet Voxels
A sparse grid of colored unit cubes — a puppet built out of voxels instead of bones/parts. State only: knows nothing about how it gets drawn (see VoxelPuppetPainter in voxel_puppet_painter.dart) — same state/render split as every other product in this factory. Coordinates are grid-cell indices (0..size-1 per axis), not world units.
VoxelPuppetPainter Voxels
Renders a VoxelPuppet as flat-shaded, depth-sorted unit cubes under a given camera — backface-culled, and faces fully hidden by a neighboring voxel are skipped before that, so this stays cheap even at a puppet's full grid size. camera is a constructor parameter, not a fixed field, so the same puppet can be painted from several angles at once (see products/voxel-asset-bakery's multi-view panel for a consumer that does exactly that).

Extensions

VoxelPuppetIo on VoxelPuppet Voxels
Serialization for VoxelPuppet — plain JSON (grid size + a flat list of {x,y,z,color} cells), not a Dart-source literal or a binary format: any consuming product can parse this with nothing but dart:convert, no extra dependency beyond dartive itself.

Functions

voxelPuppetFromJson(String source) → VoxelPuppet Voxels
Rebuilds a VoxelPuppet from VoxelPuppetIo.toJson's output (or an equivalent hand-written JSON asset).
