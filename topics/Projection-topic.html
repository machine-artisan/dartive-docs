Projection (PRJ)

IsoCamera, isoTileCorners/isoTilePath/isoTileCenter, perspectiveTurnX/Y. Notation: linear-algebra.md.

The camera as a basis

c       = (cos ε cos α, sin ε, cos ε sin α)        where the camera sits
forward = −c                                       viewing direction
right   = forward × (0,1,0) = (sin α, 0, −cos α)   always horizontal
up      = right × forward  = (−sin ε cos α, cos ε, −sin ε sin α)

The projection Π

Π(p) = scale · ( right·p , −up·p )        a 2×3 matrix, rank 2
ker Π = span(forward)                     depth is thrown away

The ground matrix G (y = 0)

The columns are the screen images of e_x and e_z:

G = [[ sin α      , −cos α       ],   =  S · R
     [ sin ε cos α,  sin ε sin α ]]

R = [[sin α, −cos α],[cos α, sin α]]   a rotation (det 1)
S = diag(1, sin ε)                     a vertical squash by 1/√3
det G = sin ε = 1/√3                   for EVERY azimuth ⇒ always invertible
G⁻¹ = Rᵀ · diag(1, √3)

α = 45°:  G ≈ [[0.707, −0.707],[0.408, 0.408]]
          +x → down-right at 30°, +z → down-left at 30°; on screen the axes meet at ≈109.5°

A point at height h moves up the screen by h · cos ε · scale (right.y = 0, up.y = cos ε).

Invariants

ID Statement Status Test
PRJ-1 (right, up, forward) is orthonormal, right × up = −forward, right.y = 0, up.y = cos ε, for every α ✅ spec_projection_test, iso_camera_test
PRJ-2 Π is linear, Π(0) = 0, Π(forward) = 0 ✅ spec_projection_test
PRJ-3 G = S·R, det G = 1/√3 for every α; G⁻¹ recovers a ground point from its screen image ✅ same
PRJ-4 Every tile is a parallelogram with area scale²/√3; isoTileCenter is the midpoint of its diagonals ✅ same, iso_grid_test
PRJ-5 Joystick zones rotated by θ classify like G⁻¹ exactly iff the screen axes are G-images of the world diagonals x = ±z, i.e. α ∈ {45°, 135°, 225°, 315°} with θ = 90° − α. Elsewhere a pure rotation misclassifies some drags ✅ same (exact at 45°, a counterexample at 30°)
PRJ-6 perspectiveTurnY/X(θ) = P·R(θ), where P is the identity with entry (3,2) = depth: projective, not affine 📄 —

Why PRJ-5 holds: the joystick assigns a drag d to whichever world component of G⁻¹d is larger. The boundaries are the world diagonals x = ±z, and their screen images are G(1,±1). At α = 45° those images are exactly the screen axes. S is diagonal, so it leaves the screen axes in place, and the rotation Rᵀ alone puts the zones in the right spots.

Classes

IsoCamera Projection
A fixed-elevation isometric camera, rotatable around the vertical axis.

Functions

isoTileCenter(IsoCamera camera, num x, num z, {double scale = 1.0, Offset origin = Offset.zero}) → Offset Projection
The screen point for the center of unit cell (x, z) — the usual anchor for a marker (avatar, pickup, prop) sitting on that cell, rather than one of its corners.
isoTileCorners(IsoCamera camera, int x, int z, {double scale = 1.0, Offset origin = Offset.zero}) → List<Offset> Projection
The 4 corners of one unit cell (x, z) of a ground-plane grid (y fixed at 0), projected through camera — in order (x,z) → (x+1,z) → (x+1,z+1) → (x,z+1), ready to build a quad for an isometric floor/wall tile. origin shifts the whole projection (e.g. to center a board on a canvas); scale matches IsoCamera.projectOrthographic's own scale.
isoTilePath(IsoCamera camera, int x, int z, {double scale = 1.0, Offset origin = Offset.zero}) → Path Projection
The same 4 corners as a closed Path, ready for canvas.drawPath.
perspectiveTurnX(double angleRadians, {double depth = 0.001}) → Matrix4 Projection
The up/down sibling of perspectiveTurnY: rotateX turns around the horizontal axis — like a trunk lid hinged front-to-back — so the visible motion is a tilt/nod (up/down), not left/right.
perspectiveTurnY(double angleRadians, {double depth = 0.001}) → Matrix4 Projection
A perspective "card flip" matrix that fakes a rotateY head/body turn for a flat 2D puppet with no real mesh — setEntry(3, 2, depth) adds the projective divide a plain rotateY lacks, so the far side visually compresses instead of just shearing. Apply around the part's own local origin (translate first, then canvas.transform(matrix.storage)).
